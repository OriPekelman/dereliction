What it is

It renders the viewport to pixels in the browser, hands a million of them to a WebGL2 simulation, and gives the words to a rigid-body engine. Gravity can pull on dark pixels only, wind can blow away everything that is not text, letters can fall into a pile, and sand can pour over them for as long as you like.

It is meant to happen to an ordinary page: leave it idle and it comes apart; the first scroll or key press brings it back.

Use it

<script src="https://cdn.jsdelivr.net/gh/OriPekelman/dereliction@main/dist/dereliction.bundle.min.js" defer
        data-attach data-idle="8000" data-preset="Avalanche"></script>

One file, one tag, no build step, no server. Or npm i dereliction and call Dereliction.attach({…}) yourself.

Tell it what should hold and what should go, in your own stylesheet:

.sticky  { --physics: solid; }   /* never moves; sand piles on it      */
.card    { --physics: rigid; }   /* one body, falls as a block         */
.block   { --physics: frame; }   /* falls as a box; words fall inside  */
.fine    { --physics: sand;  }   /* its text is loose grains           */

This italic line is marked sand. It will not survive the avalanche; it goes with the paper.

Under the hood

Two renders of the page, one with the text made transparent, are diffed into a pixel-exact ink mask. Particle state lives in float textures; one fragment shader is the physics step. Bodies come from matter.js and are rasterised every frame into an obstacle map, which is what the sand piles on. Chrome, Firefox and Safari 15+, anything with WebGL2.

Prefer pixel-perfect captures? A build-time prerender or a small Playwright service are included too. Neither is required.
